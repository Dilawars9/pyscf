What this example shows

Idealized tetrahedral butane endpoints, with a fixed atom mapping and reference bond graph. All __IMAGE_COUNT__ requested images enter geodesic optimization; none are added just for playback.

This is a geometric interpolation, without a physical time axis or an energy-minimized reaction path. Optimizer convergence is not certified. The Cartesian baseline connects the same aligned endpoint frames.
